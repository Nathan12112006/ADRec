## Agent skills

### Issue tracker

Issues and specs live as local Markdown files under `.scratch/<feature>/`. Before creating, fetching, or updating tickets or specs, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before triaging issues, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single root `CONTEXT.md` and `docs/adr/`. Before exploring the codebase or naming domain concepts, read `docs/agents/domain.md`.
